INSTAGRAM ANALYZER - VERSIONE GRATUITA

Questa è una base funzionante dell'interfaccia.
Per non chiedere la password Instagram, la versione definitiva deve usare l'esportazione ufficiale dei dati Instagram oppure un'autorizzazione ufficiale Meta quando disponibile.

Funzioni previste:
- follower
- seguiti
- segui ma non ti seguono
- ti seguono ma non li segui
- storico follower persi/nuovi
- ricerca utenti
- dashboard mobile

Non vengono promesse:
- elenco dei visitatori del profilo
- elenco certo di chi ti ha bloccato

Questi dati non sono normalmente disponibili in modo affidabile tramite API ufficiali.
